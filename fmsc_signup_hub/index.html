! How to Create Your Free Google Sheet Webhook (Takes 2 Minutes)
  1. Open sheets.new in your browser and name the spreadsheet "Sai FMSC Volunteer Roster".
  2. In the top menu, click Extensions → Apps Script.
  3. Delete all code in the script editor window, then paste the code block below.
  4. Click the blue Deploy button (top right) → New deployment.
  5. Click the gear icon next to "Select type" → select Web app.
  6. Set Execute as: Me.
  7. Set Who has access: Anyone (Essential so the webpage can send sign-ups).
  8. Click Deploy, grant Google permissions, and copy the generated Web app URL (ends in /exec).
  9. Paste that Web App URL in the field above and click Save Sheet Settings!
