# Sai Seva - FMSC Volunteer Group Hub (Phoenix SSSGC)

A dedicated, mobile-friendly web application built for the **Saibaba Group Phoenix SSSGC** to simplify Feed My Starving Children (FMSC) group volunteering sign-ups, multi-month scheduling, and WhatsApp/Email communications.

---

## Why this app was created

- **No More Re-typing:** Eliminates the repetitive manual work of copying and pasting FMSC join URLs, codes, and dates into WhatsApp or emails every month.
- **Multi-Month Scheduling:** Allows devotees and families to view and sign up for subsequent months (November, December, January, etc.) in advance.
- **One-Click Actions:**
  - 🚀 Direct join link to `fmsc.org` with join code pre-filled.
  - 📋 Quick 10-second center headcount RSVP.
  - 📅 Add to Google Calendar & Apple/Outlook (.ics).
  - 🗺️ One-tap navigation to the Tempe FMSC facility (1100 W Grove Pkwy).
  - 👟 FMSC guidelines summary (closed-toe shoes, no jewelry FDA cleanroom rules, age 5+ limits).
- **Organizer Magic Tools (for Coordinator Manjunatha):**
  - 🟢 1-Click WhatsApp invite generator with automatic formatting and direct share.
  - 📧 1-Click Email template generator.
  - ➕ Add a new month's session in 30 seconds by pasting the FMSC join code.
  - 📋 1-Click roster export to copy volunteer names directly into FMSC's reservation page.

---

## Quick Start (Local)

Double-click `run_fmsc_hub.bat` or run:

```bash
python fmsc_signup_hub/app.py
```

Then visit [http://localhost:8005](http://localhost:8005).
